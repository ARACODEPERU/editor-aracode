# Aracode Editor

Un editor de texto WYSIWYG ligero, moderno y altamente portable.

## Instalación

```bash
npm install editor-aracode
```

## Uso Básico

```javascript
import AracodeEditor from 'editor-aracode';
import 'editor-aracode/dist/aracode-editor.css';

const editor = new AracodeEditor('#editor', {
    // opciones...
});
```
